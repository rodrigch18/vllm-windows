vLLM for Windows

Run vLLM natively on Windows 10/11, without WSL or Docker. A native MSVC + CUDA 13 build of the vLLM inference and serving engine, with prebuilt wheels and an OpenAI-compatible server.

Requirements

  • Windows 10 or 11, x64, with an NVIDIA driver that supports CUDA 13.
  • For the prebuilt wheels: an NVIDIA RTX 50 series GPU (Blackwell, compute capability 12.0) and CPython 3.12 or 3.14. Other GPUs: build from source.
  • Visual Studio Build Tools (C++ workload) and a CUDA 13 toolkit. FlashInfer compiles some kernels on first use, so vLLM needs the compiler even with the prebuilt wheels. Patch the toolkit's cuda.h once with fix_cuda_13_align.py (see the README).

Install

Create a virtual environment, then install in this order: PyTorch, the Windows FlashInfer wheels, then vLLM. The order matters: otherwise pip pulls the Linux-only FlashInfer package from PyPI.

Wheels and SHA256 checksums: vLLM release, FlashInfer for Windows release.

Run a server

Open a command prompt with the MSVC x64 environment and CUDA on PATH (needed the first time, while kernels are compiled and cached), activate the venv and start the OpenAI-compatible server:

"%VISUAL_STUDIO_INSTALL_PATH%\VC\Auxiliary\Build\vcvarsall.bat" x64
set "PATH=%CUDA_PATH%\bin;%PATH%"
.venv\Scripts\activate
vllm serve YOUR_MODEL --host 127.0.0.1 --port 8000

Then point any OpenAI-compatible client at http://127.0.0.1:8000/v1.

FAQ

Can vLLM run on Windows without WSL?

Yes. Upstream vLLM supports Linux only, so on Windows it normally runs inside WSL2. This fork is a native Windows build (MSVC + CUDA 13) that installs with pip and runs directly on Windows 10/11.

Does it work on RTX 30 or RTX 40 series GPUs?

The prebuilt wheels target RTX 50 series only. For other NVIDIA GPUs, build the wheel from source and set TORCH_CUDA_ARCH_LIST to your GPU (for example 8.6 for RTX 30, 8.9 for RTX 40).

Why do I need Visual Studio Build Tools and the CUDA toolkit to run it?

Some FlashInfer and DeepGEMM kernels are compiled the first time they are used (JIT) and then cached, which needs nvcc and the MSVC compiler.

Does multi-GPU (tensor / pipeline parallel) work?

Yes, with a Windows build of NCCL. See the README.

Is this an official vLLM project?

No. It is a community fork and is not affiliated with or endorsed by the vLLM project. Report Windows-specific problems in this fork's issues, and general vLLM questions upstream.
